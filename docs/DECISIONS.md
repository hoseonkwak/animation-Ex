# Kwak Motion Lab 결정 기록

결정은 새로운 논의로 변경되기 전까지 구현의 기본값으로 사용한다.

## 2026-09-15

### D-001 제품 방향

- 상태: 확정
- 결정: Animation Lab과 Tutorial을 결합한 공개형 개인 도구로 리뉴얼한다.
- 이유: 개인 레퍼런스 활용과 공개 학습 콘텐츠의 확장성을 함께 확보한다.

### D-002 구현 기반

- 상태: 확정
- 결정: 사용자 애플리케이션은 Vue를 사용한다.
- 비고: 세부 기술과 버전은 구현 설계 단계에서 정한다.

### D-003 공개 콘텐츠 형식

- 상태: 확정
- 결정: 공개되는 모든 애니메이션은 실제 코드로 실행한다. 이미지, GIF와 영상은 실행 화면을 대체하지 않는다.

### D-004 수집 방식

- 상태: 확정

### D-005 공개 승인

- 상태: 확정
- 결정: 초기에는 관리자 승인 후 공개한다. 충분한 검증 이력이 쌓인 뒤 조건부 자동 공개로 발전시킨다.

### D-006 콘텐츠 단위

- 상태: 확정
- 결정: 애니메이션이 포함된 완결된 섹션을 하나의 콘텐츠로 다룬다.

### D-020 하네스 확장 방식

- 상태: 확정
- 결정: 현재 필요한 프로젝트 지침, 아키텍처, 데이터 계약, 품질 게이트와 Phase 수용 기준을 문서화한다. Skill, Subagent와 MCP는 실제 반복 절차와 도구 경계가 생길 때 추가한다.
- 이유: 이름뿐인 역할과 절차를 미리 늘리지 않고 구현에서 확인된 입력, 출력과 실패 패턴을 하네스에 반영하기 위해서다.

### D-021 초기 운영 비용

- 상태: 확정
- 결정: Phase 1은 월 고정비 없이 운영할 수 있는 구성을 우선한다. Vue 정적 파일과 API는 Cloudflare Workers, 메타데이터는 D1, 예약 수집은 GitHub Actions를 기본값으로 사용한다.
- 제약: 무료 한도를 자동으로 넘겨 과금되는 기능은 별도 결정 없이 활성화하지 않는다. AI API와 별도 검색 서비스는 Phase 1 범위에서 제외한다.
- 전환: 무료 한도 접근, 처리 지연 또는 운영 장애가 반복될 때 실제 사용량과 예상 비용을 근거로 유료 전환을 다시 결정한다.

### D-022 Phase 1 실행 데이터

- 상태: 확정
- 결정: 원본 CodePen 콘텐츠는 검증된 CodePenRef로 실행하고, 자체 제작 콘텐츠는 활성 CodePackageVersion으로 실행한다. 공개 Entry는 두 실행 방식 중 정확히 하나를 가져야 한다.
- 이유: 원본 Pen 전체 코드를 불필요하게 복제하지 않으면서 모든 공개 Preview가 실제 코드로 실행된다는 원칙을 유지한다.

### D-023 Phase 1 API와 저장소

- 상태: 확정
- 결정: 공개, 관리자와 수집 API는 `/api/v1` 계약을 사용하고 Phase 1 데이터는 D1 관계형 스키마에 저장한다. 관리자 수정은 version 충돌 검사, 승인은 원자성과 멱등성을 보장한다.

### D-024 WSSS 수집 경계

- 상태: 확정
- 결정: WSSS에서는 게시물과 공개 CodePen 참조 메타데이터만 수집한다. ZIP, 이미지와 첨부 파일은 받지 않으며 CodePen 페이지 자체를 자동 크롤링하지 않는다.
- 검증: 원본 Pen은 관리자 화면에서 공식 CodePen embed로 실제 실행을 확인한다.

### D-025 관리자 검수 방식

- 상태: 확정

### D-026 단계별 내비게이션

### D-030 목록 썸네일과 수동 실행

- 상태: 확정
- 결정: Home, Explore와 관련 목록의 예제 카드는 CodePen 공식 스크린샷을 선택용 썸네일로 보여준다. 사용자가 썸네일을 누르면 같은 자리에서 실제 CodePen 실행 화면으로 전환한다. 실행 화면을 정적 이미지로 대체하지 않으며, 목록에서는 자동 실행하지 않는다.
- 이유: 다수의 카드에 `실행 대기 중` 상태를 반복하기보다 예제의 생김새를 먼저 비교하고 원하는 예제만 실행할 수 있게 한다.
- 제약: 동시 실행은 최대 2개, 화면 밖 실행 iframe은 제거한다. 썸네일을 가져오지 못해도 제목과 실행 행동은 유지한다.
- 썸네일 출처: [CodePen 공식 스크린샷 URL 문서](https://blog.codepen.io/documentation/screenshots/). 외부 이미지 URL을 그대로 사용하며 리포지토리에 복제하지 않는다.

### D-031 홈 정보 구조와 Liquid 디자인

- 상태: 확정
- 결정: Home은 짧은 제품 제목 다음에 카테고리와 실행 가능한 예제 목록을 바로 보여준다. 이용 방법, 컬렉션, 패턴과 제보 안내는 Home에서 제거하고 각 전용 경로에서 제공한다.
- 시각 기준: 반투명 표면, 부드러운 곡선과 은은한 배경 색 번짐을 사용하는 Liquid 디자인을 적용한다. 재질 효과는 내비게이션과 콘텐츠 그룹 구분에 제한하고 예제 썸네일과 탐색 정보가 시각적 중심이 되게 한다.
- 접근성: 투명도 감소와 모션 감소 환경에서는 불투명 표면과 정적인 상태로 대체한다.

### D-032 환경 분리와 무료 한도 보호

- 상태: 확정
- 결정: local, preview와 production은 서로 다른 Worker 이름과 D1 binding을 사용한다. Cloudflare Vite 빌드 전에 `CLOUDFLARE_ENV`를 고정하고 생성된 배포 설정을 dry-run으로 확인한다.
- 운영 기준: Worker 요청, D1 읽기와 쓰기 중 가장 높은 사용률이 무료 한도의 70% 이상이면 경고하고 90% 이상이면 신규 수집 batch를 중지한다. 공개 조회와 진행 중인 수집의 완료 기록은 유지한다.
- Preview: 전체 검색 색인을 차단하고 예약 수집을 기본 중지한다. 로컬 관리자 모의 인증은 preview와 production에서 비활성화한다.

### D-033 Preview Access 결제 등록 보류

- 상태: 확정
- 확인일: 2026-09-22
- 결정: Cloudflare Zero Trust 무료 플랜 활성화 과정에서 결제 카드와 무료 한도 초과분 자동 청구 동의를 요구하므로 Access 활성화를 보류한다.
- 이유: Phase 1의 월 고정비 0원과 무료 한도를 자동으로 넘기는 유료 기능 비활성 원칙을 유지한다.
- 현재 보호: Worker는 `ADMIN_EMAIL`과 Cloudflare Access 이메일 헤더가 모두 일치하지 않으면 관리자 API를 401로 차단한다. Access가 연결되기 전에는 원격 관리자 기능을 사용하지 않는다.
- 재검토: 카드 등록 없는 무료 활성화 방법을 확인하거나 사용자가 초과 과금 가능성을 명시적으로 승인할 때 별도 결정한다.

### D-034 Production 최초 공개

- 상태: 확정
- 확인일: 2026-09-23
- 결정: Phase 1 Production을 `kwak-motion-lab-production.kwak-motion-lab.workers.dev`에 우선 공개한다. 전용 도메인은 실제 이용과 브랜드 운영 기준이 정해질 때 연결한다.
- 격리: Production은 Preview와 다른 Worker, D1, Turnstile 위젯과 ingestion 인증값을 사용한다.
- 관리자: Cloudflare Access가 보류된 동안 Production 관리자 API는 모든 원격 요청을 401로 차단한다. 공개 탐색과 URL 제보 기능은 비로그인으로 제공한다.

### D-035 무료 관리자 인증을 GitHub OAuth로 전환

- 상태: 확정
- 확인일: 2026-10-15
- 결정: Cloudflare Access 대신 GitHub OAuth 웹 흐름으로 owner 한 명을 인증한다. GitHub 사용자명은 변경될 수 있으므로 `ADMIN_GITHUB_USER_ID`의 숫자 ID와 일치하는 계정만 허용한다.
- 세션: Worker가 GitHub 사용자 ID를 확인한 직후 OAuth access token을 폐기하고, 환경별 `ADMIN_SESSION_SECRET`으로 서명한 8시간 HttpOnly 세션 쿠키를 발급한다. 쿠키는 `Secure`, `SameSite=Lax`이며 발급 origin을 audience로 포함한다.
- 보호: OAuth `state` 검증, 쓰기 API의 same-origin 검사, 숫자 owner ID 재검사와 환경별 비밀값 분리를 함께 적용한다. 사용자 DB와 일반 사용자 로그인은 추가하지 않는다.
- 로컬: localhost의 `LOCAL_ADMIN_SIMULATION`만 기존 `X-Local-Access-Email` 모의를 허용한다. Preview와 Production에서는 이 헤더를 무시한다.
- 운영: Preview와 Production은 각 callback URL에 맞는 별도 GitHub OAuth App과 비밀값을 사용한다. Production 설정이 완료되기 전에는 관리자 API가 계속 401을 반환한다.
- 관계: D-033의 Cloudflare Access 결제 등록 보류를 유지하며, D-034의 원격 관리자 차단은 GitHub OAuth 설정과 검증이 완료될 때까지의 상태로 대체한다.
- 검증: 2026-10-15에 Preview와 Production 각각의 OAuth App, Worker secret, 실제 owner 승인과 Candidate Inbox 로딩을 확인했다.

### D-036 관리자 진입과 후보 사전 분류

- 상태: 확정
- 확인일: 2026-10-15
- 결정: 공개 화면 푸터에 `관리자` 링크를 두고 기존 GitHub OAuth owner 인증으로 접근을 보호한다. 로고 연속 클릭과 같은 숨은 동작은 사용하지 않는다.
- 검수: 관리자 Inbox는 모든 승인 대기 후보를 주소 형식, 같은 Pen 중복, 기록된 실패, 필수 정보, 실제 Preview 확인 상태로 읽기 전용 분류한다. Hero 신호는 우선 검수 필터로 제공하며 태그 확정이나 승인을 자동으로 수행하지 않는다.
- 한계: 외부 요청의 403 또는 네트워크 오류는 Pen의 404 증거가 아니다. 접근 불가는 기존 기록 또는 관리자 수동 확인으로 판단한다.

### D-037 후보 문구 자동 생성과 한 번의 승인

### D-041 자동 공개의 작은 묶음과 표본 게이트

- 상태: 확정 (Production 예약 검사 허용, 자동 게시 표본 대기)
- 확인일: 2026-10-15
- 결정: Browser Run에서 하루 최대 8개를 검사하고, 같은 카테고리에서 엄격한 실행 증거를 가진 3개 이상만 묶는다. 묶음마다 무작위 1개를 소유자가 기존 관리자 Preview에서 확인·승인한다. 이 표본이 공개된 뒤 나머지를 다음 예약 실행에서 자동 공개한다. 표본 거절·정보 변경·오래된 검사는 묶음 전체를 보류한다.
- 안전 경계: 구체적인 제안 제목과 확정 탐색 태그·제작자·라이선스가 있는 원본 Pen만 대상으로 한다. 양성 대조군, Embed와 Result의 200 응답, 비어 있지 않은 화면, 두 구간의 화면 변화, 오류 없음이 모두 필요하다. 스크롤·호버·클릭형 및 판정 불가 항목은 자동 공개하지 않는다. 자동 검사 결과는 관리자 수동 확인과 다른 validator로 기록한다.
- 운영: D1 중지 스위치는 기본 중지다. 소유자는 관리자 화면에서 예약 검사를 허용하거나 즉시 중지하고 자동 공개 묶음을 일괄 취소할 수 있다. 무료 Browser Run 시간 안에서 하루 1회만 예약한다.
- 문구·난이도: 기존 후보의 빈 한국어 요약과 slug는 수집 때 사용한 규칙으로 채운다. 난이도 정보가 없는 자동 공개 항목은 임시로 `intermediate`를 사용하고 featured는 꺼둔다. 이는 학습 난이도에 대한 검증된 평가가 아니므로 추후 별도 분류가 필요하다.
- 이유: 후보 전체를 사람이 승인하는 부담을 줄이되, 실제 브라우저 실행과 공개 전 소유자 표본 판단을 필수로 유지한다.

### D-042 늦게 승인한 표본의 실행 증거 갱신

- 상태: 확정
- 확인일: 2026-10-19

- 이유: 소유자가 표본을 며칠 뒤 승인해도 오래된 검사 때문에 정상 묶음이 무조건 실패하지 않도록 하면서, 공개 시점에는 새로운 실행 증거를 요구한다. 대기 묶음의 후보 수는 최초 하루 상한 8개 이내다.

### D-043 반복 승인 없는 제한적 자동 공개

- 상태: 확정 (Production 자동 게시 확인)
- 확인일: 2026-10-20
- 결정: D-041의 묶음마다 표본을 사전 승인하는 절차는 반복 작업이므로 없앤다. Browser Run 교정 표본이 있는 `Animation/GSAP` 카테고리부터, 하루 최대 8건의 엄격한 실행 검사와 출처·태그·중복·메타데이터 검사를 모두 통과한 묶음을 예약 실행에서 공개한다. 소유자는 공개 후 표본을 선택적으로 확인하고, 이상이 있으면 즉시 중지·묶음 취소한다. 다른 카테고리는 별도 교정과 오류율 분석 전까지 자동 공개하지 않는다.
- 기존 대기 묶음: Production의 `awaiting-sample` 묶음도 다음 예약 실행에서 모든 후보의 상태·버전·검사 증거를 재확인하고, 72시간이 지난 증거는 양성 대조군과 함께 재검사해 통과한 경우에만 공개한다. 사람이 이미 승인한 표본은 재공개하지 않는다.
- 안전 경계: 최신 검증 기록의 validator가 `browser-run-auto`이고 저장된 증거가 엄격한 실행 조건을 만족해야 한다. 원본 제목을 공개 제목으로 사용하고 규칙 기반 한국어 요약을 생성해 수집 때 제안한 문구의 오탈자를 전파하지 않는다. 중간 실패 시 이미 게시한 항목을 되돌리고 예약 실행을 중지한다.
- 이유: 소유자의 목표는 표본마다 버튼을 누르지 않고 안전한 후보를 계속 축적하는 것이다. 실제 브라우저 검사와 공개 후 표본 점검·취소 경로를 유지한다.
- 운영 확인: 2026-10-21 예약 실행에서 기존 대기 묶음 6건과 새 GSAP 묶음 5건이 게시됐다. 새 묶음은 사전 표본 승인 없이 게시됐으며 D1 실행·묶음·항목 기록과 공개 API가 일치했다.

### D-049 예약 자동 공개 대상 확대

- 상태: 운영 확인
- 확인일: 2026-10-27
- 결정: GSAP 후보 부족으로 예약 실행이 계속 `no-batch`가 되면 교정한 `Animation/Loading` 후보를 같은 엄격한 Browser Run 게이트로 자동 공개한다. 한 실행에서 한 카테고리의 최대 8건만 검사하며, 3건 이상 통과해야 게시한다. Loading은 원본 제목에 loader/loading/preloader/spinner/progress 표기가 있는 후보만 대상으로 한다.
- 운영: 출처·라이선스·중복·확정 태그·메타데이터·실행 증거를 재확인한다. 공개 후 표본을 확인하고 문제가 있으면 중지·묶음 취소한다. 다른 카테고리는 별도 교정과 오분류 분석 뒤에만 추가한다.
- 이유: 수집 후보 대부분이 GSAP 외 카테고리여서 기존 예약 실행만으로는 대기 수가 줄지 않았다. Loading 표본에서 실행 검사는 통과했으나 실제 로더가 아닌 예제를 발견해 제목 조건을 추가했다.
- 결과: 2026-10-27 운영 실행에서 Loading 8건 검사, 7건 게시, 1건 보류를 확인했다. `review`는 1,843건에서 1,836건으로 감소했다.

### D-050 남은 CodePen 후보의 전량 공개

- 상태: 운영 확인
- 확인일: 2026-10-27
- 결정: 소유자의 전량 공개 요청에 따라 현재 `review`인 CodePen 후보를 예제 목록에 올린다. 실행 확인이 없는 항목은 `runtime_verified=0`으로 저장하고 카드와 상세 화면에 `실행 미확인`을 표시한다. 공개 API에서도 이 값을 제공한다. 원본 CodePen Embed를 실행하며, 코드나 에셋을 서비스 내부로 복사하지 않는다.
- 예외: D-043·D-049의 자동 검증 후 공개 규칙과 Phase 1의 Preview 선확인 게이트는 이 일회성 공개에 한해 적용하지 않는다. 주소·작성자·라이선스 근거·중복 등 구조적 조건은 유지한다. 이용 불가 Pen이나 부적절한 콘텐츠가 발견되면 기존 공개 중지 경로를 사용한다.
- 운영: 일괄 실행 ID와 항목별 연결을 D1에 남기고, 재실행해도 중복 등록하지 않는다. 새로 수집되는 후보의 자동 공개 정책은 D-049를 따른다.
- 결과: 운영 D1에서 1,836건 게시와 `review` 0건, 전체 공개 1,876건을 확인했다. 일괄 공개 Entry는 모두 `runtime_verified=0`이며 공개 API에 반영됐다.

### D-053 Practice Kit의 고정 GSAP 실행 환경

- 상태: 로컬 구현 검증 중
- 확인일: 2026-10-29
- 결정: 자체 제작 GSAP Kit에 한해 `gsap@3.15.0`을 허용한다. 앱에 고정 설치한 라이브러리 코드를 격리 Preview에 넣어 실행하고, 빈 코드 연습이나 다른 Kit에는 주입하지 않는다. 원격 스크립트·스타일·에셋은 계속 금지한다. CodePen 내보내기에는 같은 버전의 외부 스크립트와 [GSAP 라이선스](https://gsap.com/community/standard-license/) 안내를 넣는다.

- 근거: [GSAP 설치 문서](https://gsap.com/docs/v3/Installation/), [CodePen prefill 계약](https://blog.codepen.io/docs/api/post-to-prefill-pen/).
- 출시 경계: 현재 GSAP Kit은 로컬 fixture다. 라이브러리 버전 변경은 새 코드 버전과 브라우저 검증 후 진행한다.

### D-055 master 자동 배포

- 상태: 운영 확인
- 확인일: 2026-10-29
- 결정: `master` push의 CI가 통과하면 같은 commit을 Preview에 배포하고 공개·관리자 경계 smoke를 통과한 뒤 Production Worker를 배포하고 다시 smoke를 실행한다. 실패하면 다음 배포 단계로 넘어가지 않는다. 이전 commit이 대기 중 최신 `master`로 교체되면 오래된 commit은 배포하지 않는다.
- 인증: GitHub Actions의 `production` 환경을 `master`로 제한하고, Cloudflare 계정의 `Workers Scripts Write`만 가진 1년 만료 API token을 secret으로 둔다. 공개 Turnstile site key는 저장소 Actions 변수로 분리한다. Worker의 OAuth·Turnstile·수집 secret은 Cloudflare에 그대로 둔다.
- 데이터 경계: Worker 자동 배포는 D1 migration이나 Practice Kit seed를 자동 적용하지 않는다. 스키마 변경은 운영 D1 백업과 별도 migration 확인 뒤 `master` 배포 전에 적용한다. D-052~D-054의 Kit fixture는 소유자 검수와 공개 게이트 전까지 Production에 입력하지 않는다.
- 결과: 2026-10-29 `master`의 `bd41e2e`에서 GitHub Actions 검증, Preview 배포·smoke, Production 배포·smoke가 모두 통과했다. Production Worker 새 버전의 100% 활성화와 Practice 페이지 200 응답을 확인했다.
