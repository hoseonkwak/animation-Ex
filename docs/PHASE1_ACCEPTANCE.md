# Phase 1 완료 기준

문서 상태: Draft v0.1
목표: Executable Library가 실제로 사용할 수 있는 상태인지 판정한다.

## 1. 공개 사용자 경험

- [ ] `P1-UX-01` Vue 기반 애플리케이션이 공개 URL에서 로드된다.
- [ ] `P1-UX-02` 로그인 없이 Home, Explore, Sections와 상세 화면을 사용할 수 있다.
- [x] `P1-UX-03` Light가 최초 기본 테마다.
- [ ] `P1-UX-04` 사용자가 선택한 테마가 브라우저에 저장된다.
- [x] `P1-UX-05` 한국어 UI와 설명이 표시된다.
- [x] `P1-UX-06` Phase 1에 제공되지 않는 Practice와 Learn 메뉴가 노출되지 않는다.

## 2. 콘텐츠

- [x] `P1-CONTENT-01` 기존 GSAP 목록의 예제 15개가 새 데이터 구조로 이전된다.
- [x] `P1-CONTENT-02` 기존 예제의 제목, 태그와 원본 CodePen 정보가 정리된다.
- [ ] `P1-CONTENT-03` WSSS 관련 카테고리에서 유효한 CodePen 후보를 수집할 수 있다.
- [x] `P1-CONTENT-04` 삭제되거나 실행되지 않는 Pen은 공개되지 않는다.
- [x] `P1-CONTENT-05` 중복 Pen은 canonical URL 기준으로 합쳐진다.
- [x] `P1-CONTENT-06` 관리자 승인 전 콘텐츠는 공개되지 않는다.

## 3. 탐색

- [x] `P1-DISCOVERY-01` 키워드 검색이 제목, 설명과 태그를 찾는다.
- [x] `P1-DISCOVERY-02` Technology, Trigger, Motion, Section, Technique, Difficulty 필터가 동작한다.
- [x] `P1-DISCOVERY-03` 여러 필터를 함께 적용할 수 있다.
- [x] `P1-DISCOVERY-04` 필터를 URL로 공유하거나 다시 열었을 때 복원할 수 있다.
- [x] `P1-DISCOVERY-05` 결과 없음 상태가 다음 탐색 방법을 제공한다.
- [ ] `P1-DISCOVERY-06` Hero Section 허브가 있다.
- [x] `P1-DISCOVERY-07` Wide 4열, Desktop 3열, Tablet 2열과 Mobile 1열로 카드가 배치된다.

검색 입력에는 자연스러운 문장을 넣을 수 있지만 Phase 1은 이를 일반 키워드로 처리한다. AI 필터 해석은 별도 비용과 품질 검토 후 활성화한다.

## 4. 실행 Preview

- [x] `P1-PREVIEW-01` 모든 공개 카드는 실제 실행 코드 또는 원본 CodePen을 보여준다.
- [x] `P1-PREVIEW-02` 화면에 보이는 Preview만 로드한다.
- [x] `P1-PREVIEW-03` 동시에 실행되는 Preview 수를 제한한다.
- [ ] `P1-PREVIEW-04` 무거운 예제는 Run 이후 실행한다.
- [x] `P1-PREVIEW-05` 화면 밖 Preview는 중지하거나 제거한다.
- [x] `P1-PREVIEW-06` 실행 오류가 사용자 페이지 전체를 중단시키지 않는다.
- [x] `P1-PREVIEW-07` 영상, GIF 또는 녹화 화면을 실행 Preview로 사용하지 않는다.

## 5. 상세

- [ ] `P1-DETAIL-01` 제목, 설명, 태그, 난이도와 콘텐츠 상태가 표시된다.
- [ ] `P1-DETAIL-02` 실행, 재시작, 전체 화면과 새 창 기능이 있다.
- [ ] `P1-DETAIL-03` 원본 CodePen 콘텐츠는 제작자와 원본 링크를 표시한다.
- [ ] `P1-DETAIL-04` 관련 예제와 Pattern을 표시할 수 있다.
- [ ] `P1-DETAIL-05` Practice 미구현 상태에서 기능을 사용할 수 있는 것처럼 표시하지 않는다.

## 6. 관리자

- [ ] `P1-ADMIN-01` 소유자 한 명만 관리자 화면에 접근할 수 있다.
- [ ] `P1-ADMIN-02` Candidate 목록과 상세를 볼 수 있다.
- [ ] `P1-ADMIN-03` Reference를 일괄 승인할 수 있다.
- [ ] `P1-ADMIN-04` 제목, 작성자와 태그를 수정할 수 있다.
- [ ] `P1-ADMIN-05` 중복 병합과 거절이 가능하다.
- [ ] `P1-ADMIN-06` 공개 콘텐츠를 중지할 수 있다.
- [ ] `P1-ADMIN-07` 각 결정과 실패 이유가 기록된다.
- [ ] `P1-ADMIN-08` 승인 불가 이유를 한 화면에서 확인할 수 있다.
- [x] `P1-ADMIN-09` CodePen Preview의 확인 시각과 viewport가 기록된다.
- [ ] `P1-ADMIN-10` 일괄 승인이 개별 Preview 확인과 필수 조건을 우회하지 않는다.

## 7. 개인 기능

- [ ] `P1-LOCAL-01` 로그인 없이 예제를 저장할 수 있다.
- [ ] `P1-LOCAL-02` `저장한 예제`와 `나중에 연습`을 구분한다.
- [ ] `P1-LOCAL-03` 브라우저를 다시 열어도 목록이 유지된다.
- [ ] `P1-LOCAL-04` 브라우저 데이터라는 한계를 사용자에게 알린다.

## 8. 검색과 공유

- [ ] `P1-SEO-01` 공개 상세와 Section에 고유 URL이 있다.
- [ ] `P1-SEO-02` 공개 콘텐츠만 검색엔진에 노출된다.
- [ ] `P1-SEO-03` 관리자, Candidate와 임시 상태는 색인되지 않는다.
- [ ] `P1-SEO-04` 공유용 제목, 설명과 대표 정보가 있다.

## 9. 운영

- [ ] `P1-OPS-01` WSSS 신규 수집을 반복 실행해도 중복이 생기지 않는다.
- [ ] `P1-OPS-02` 실패한 작업은 상태와 원인을 남긴다.
- [ ] `P1-OPS-03` 수집량과 공개량을 구분해 확인할 수 있다.
- [ ] `P1-OPS-04` 공개 Preview 오류를 관리자 화면에서 확인할 수 있다.
- [ ] `P1-OPS-05` 백업과 복구 절차가 문서화된다.
- [ ] `P1-OPS-06` 일일 Worker 요청과 D1 읽기, 쓰기 사용량을 확인할 수 있다.
- [ ] `P1-OPS-07` 무료 한도 70%에서 경고하고 90%에서 예약 수집을 중지한다.
- [ ] `P1-OPS-08` 예약 수집이 멈춰도 수동 실행으로 복구할 수 있다.
- [ ] `P1-OPS-09` WSSS parser 구조 변경을 빈 성공으로 처리하지 않는다.
- [ ] `P1-OPS-10` WSSS 수집기는 ZIP, 이미지와 CodePen 페이지를 자동으로 내려받지 않는다.
- [ ] `P1-OPS-11` Preview 환경은 production D1에 쓰지 못한다.
- [ ] `P1-OPS-12` AI API와 별도 유료 검색 서비스 없이 Phase 1 핵심 흐름이 동작한다.

## 10. 완료 판정

체크리스트를 단순히 표시하는 것으로 완료하지 않는다. 각 항목에는 자동 검사 결과, 수동 검수 기록, 화면 링크 또는 재현 가능한 실행 명령 중 하나의 증거가 있어야 한다.
