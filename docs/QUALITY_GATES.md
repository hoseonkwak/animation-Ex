# 품질 게이트

문서 상태: Draft v0.1

## 1. 원칙

- 자동 판단과 결정적 검사를 분리한다.
- 경고와 실패를 구분한다.
- 실패한 항목은 이유 없이 다음 상태로 이동하지 않는다.
- 새 공개 버전이 실패하면 마지막 정상 버전을 유지한다.

## 2. Candidate Gate

### 필수 통과

- URL 형식이 유효함
- canonical URL 또는 판정 실패 사유가 있음
- 출처 타입을 결정함
- 중복 검사를 수행함
- 접근 상태를 기록함

### 관리자 검토로 보내는 조건

- canonical URL 불확실
- 원작자 불확실
- 중복 가능성이 있으나 확정할 수 없음
- 라이선스 또는 원본 관계 불확실

## 3. CodePen Reference Gate

### 필수 통과

- 공개 Pen에 접근 가능함
- Preview가 실행됨
- creator와 canonical URL이 있음
- 라이선스 정보가 있음
- 임베드가 사용자 화면에서 동작함
- 금지된 또는 깨진 외부 리소스가 없음
- 승인 작업 후 활성 CodePenRef가 Entry와 1:1로 연결됨

## 4. Generated Code Gate

### Schema

- `CONTENT_SCHEMA.md`의 CodePackage 계약을 만족함
- 허용된 외부 리소스만 사용함
- 원본 로고, 문구와 독점 에셋을 포함하지 않음

### Static

- 파싱 오류 없음
- 명백한 무한 반복과 금지 API 없음
- 상위 페이지 접근 코드 없음
- 팝업, 다운로드와 임의 폼 전송 없음
- 관리자 비밀 또는 환경 값 없음

### Runtime

- sandbox에서 로드됨
- 처리되지 않은 JavaScript 오류 없음
- Preview heartbeat 정상
- 재시작 가능
- 지정한 사용자 입력에 반응함
- 실행 제한을 초과하지 않음
- 화면 밖에서 중지 또는 제거 가능

### Responsive

- 최소 desktop 기준 화면 정상
- 콘텐츠가 기준 viewport 밖으로 의도치 않게 잘리지 않음
- 지원하지 않는 viewport는 명시함

## 5. Practice Gate

- 시작 코드 로드 가능
- 자동 실행과 수동 실행 가능
- 실행 전 브라우저 저장 수행
- 초기화 가능
- 마지막 정상 상태 복구 가능
- 콘솔 오류를 사용자에게 표시
- CodePen prefill payload 생성 가능
- 격리 경계를 벗어나지 않음

## 6. Tutorial Gate

- 학습 목표, 난이도와 사전 지식 존재
- 모든 단계의 코드가 실행됨
- 이전 단계에서 다음 단계로 진행 가능
- 미션 판정 실패 메시지가 구체적임
- 힌트와 해답이 목표와 일치함
- 최종 코드가 공개 CodePackage와 일치하거나 차이를 설명함

## 7. 공개 후 Monitoring Gate

- 공개 콘텐츠를 한 달에 한 번 재실행
- 원본 Pen과 외부 리소스 접근 상태 확인
- 반복 오류가 발생하면 자동으로 실행을 중지하고 관리자 큐로 이동
- 새 버전 배포 후 대표 Preview smoke test 실행

## 8. 자동 공개 조건

초기에는 사용하지 않는다. 자동 공개를 시작하려면 별도 결정과 다음 자료가 필요하다.

- 충분한 수동 승인 표본
- 출처별 오류율
- false positive와 false negative 분석
- 자동 공개 취소 절차
- 점수 임계값과 근거
- 비용 및 실행 한도
