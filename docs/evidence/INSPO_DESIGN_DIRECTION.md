# InspoMCP 기반 공개 화면 시안

상태: 사용자 검토용 시안

## 참고 화면

InspoMCP의 공개 카탈로그에서 일반 디자인 키워드로 검색했다. 프로젝트의 비공개 기획 문장은 외부 서비스에 전송하지 않았다.

| 참고                   | 적용한 구성                                             | 원본                       |
| ---------------------- | ------------------------------------------------------- | -------------------------- |
| Pace Gallery 전시 목록 | 여백을 두고 실행 작품을 크게 전시하는 홈                | https://pacegallery.com/   |
| ArchDaily              | 대표 항목을 강조하고 작은 항목으로 이어지는 편집형 위계 | https://www.archdaily.com/ |
| Feather Icons          | 검색·필터·일관된 셀을 이용한 도구형 탐색                | https://feathericons.com/  |

참고 화면의 로고, 이미지, 코드, 서체를 복제하지 않았다. 홈페이지의 대표 화면과 예제 카드는 기존 CodePen 실행 iframe을 사용한다.

## 시안의 화면 구조

- Home: 서비스의 용도를 설명하는 한국어 제목 → 실제 코드가 실행되는 대표 예제와 균형 잡힌 1:1 배치 → 3단계 이용 안내 → 검색 → 실행 예제 → 적용 영역 → 컬렉션 → 패턴.
- Explore: 간결한 제목과 검색을 같은 단에 놓고, 아래에 필터와 4·3·2·1열 실행 예제 그리드를 둔다.
- 공통 셸: 작은 브랜드 마크, 한국어 내비게이션, 넉넉한 바깥 여백, 밝은 중성 배경과 Indigo 강조색을 사용한다.
- 작은 화면: 메시지 다음에 대표 실행 화면을 놓고, 필터와 예제는 단일 열로 접는다.

## 유지한 제품 조건

- 기본 테마는 Light, Dark는 선택 사항이다.
- 목록에서는 CodePen 공식 썸네일을 보여주고 클릭하면 실제 실행 iframe으로 전환한다. 실행 화면을 정지 이미지나 영상으로 대체하지 않는다.
- 초기 공개 화면은 로그인 없이 사용하며 Practice·Learn 진입점을 추가하지 않는다.
- 실행 우선순위는 홈 대표 예제에 주고 동시 실행 상한은 2개로 유지한다.

## 첫 피드백 반영

첫 시안은 전시용 영어 라벨과 어두운 프레임이 앞서 서비스의 용도를 이해하기 어려웠다. 이번 시안은 첫 제목에서 웹 애니메이션 예제 라이브러리임을 밝히고, 실제 이용 순서인 찾기 → 실행 화면 보기 → CodePen에서 코드 열기를 짧게 안내한다. 아직 제공하지 않는 사이트 내 연습 페이지는 첫 화면에서 약속하지 않는다.

## 검토할 항목

- 홈 대표 화면의 크기와 제목 위계가 적절한가.
- Explore에서 검색·필터·실행 예제를 빠르게 찾을 수 있는가.
- 모바일 첫 화면에서 대표 실행 화면이 충분히 빨리 보이는가.
