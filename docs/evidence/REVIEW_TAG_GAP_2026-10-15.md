# Production 검수 태그 누락 분석

확인일: 2026-10-15

Production D1의 `review` 후보를 읽기 전용 SQL로 집계했다. 변경 전 `정보 보완`은 865건이었다. 기존 승인 조건인 Technology 또는 Section의 확정·고신뢰 제안이 없는 후보를 카테고리별로 나누면 다음과 같다.

| 카테고리            | 건수 | 기존 태그 보유(축 무관) |
| ------------------- | ---: | ----------------------: |
| Animation/Animation |  174 |                       3 |
| Mouse/Mouse Effect  |  123 |                      25 |
| Parallax/Scroll     |  103 |                     103 |
| Particles/Particles |   73 |                       2 |
| Image/Background    |   64 |                       1 |
| Particles/Three.js  |   58 |                       1 |
| Image/Hover Effect  |   58 |                      45 |
| Particles/Canvas    |   56 |                       0 |
| Image/Image Effect  |   46 |                      18 |
| 그 밖의 UI 카테고리 |  110 |                       4 |

합계 865건. 특히 Scroll 103건은 탐색에 쓸 수 있는 Trigger 태그가 이미 있어도 기존 승인 축 제한 때문에 정보 보완으로 분류됐다. 명확한 하위 카테고리는 미확정 태그 제안으로 연결하고, 넓은 카테고리는 제목의 명시적 단서가 있을 때만 제안한다. 이 분석은 태그와 메타데이터의 정적 상태를 다룬다. 실제 CodePen 실행 및 공개 가능 여부는 소유자가 후보별로 확인해야 한다.

## 배포 후 확인

Preview와 Production에 태그 사전 migration 및 Worker를 배포하고 각각 smoke test를 통과했다. Production 관리자 화면을 새로고침한 뒤 다음 값을 확인했다.

| 분류 | 변경 전 | 변경 후 |
| --- | ---: | ---: |
| 정보 보완 | 865 | 114 |
| 실행 확인 필요 | 993 | 1,744 |
| 최종 확인 | 2 | 1 |
| 기존 실패 | 1 | 1 |

확인 시 승인 대기 총수는 1,861건에서 1,860건으로 바뀌어 있었으므로 개별 후보 상태 변화가 포함될 수 있다. 태그 규칙 변경 자체는 후보를 승인하거나 공개하지 않았다. 기존 `Mouse/Mouse Effect` 후보의 상세 화면에는 미확정 `포인터` 태그가 선택되어 보이는 것을 확인했다. `정보 보완` 필터의 세 페이지를 모두 확인한 결과, 남은 114건의 표시 사유는 모두 `애니메이션 태그 확인`이었다. 범용 카테고리와 제목에서 근거를 찾지 못한 후보는 관리자가 직접 태그를 판단해야 한다.
