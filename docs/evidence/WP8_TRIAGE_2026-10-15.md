# WP8 후보 사전 분류 및 관리자 진입 검증

검증일: 2026-10-15

## 변경

- 공개 화면 푸터에 `관리자` 링크를 추가했다. 기존 GitHub OAuth owner 인증은 그대로 적용된다.
- 관리자 Inbox는 전체 `review` 후보를 읽기 전용으로 사전 분류하고 50개씩 탐색한다. Hero 신호는 별도 필터다.
- 분류 기준은 CodePen 주소 형식, 같은 Pen의 다른 후보·공개 예제, 기록된 접근·실행 실패, 필수 공개 정보, 현재 Pen의 최신 실행 확인이다.
- 검사 결과나 메타데이터를 저장하면 분류 집계를 다시 읽는다. 사전 분류는 승인이나 거절을 자동 실행하지 않는다.

## Production 관찰

| 항목                     |  건수 |

| 승인 대기                | 1,861 |

| 주소 형식 오류·중복 의심 |  각 0 |

기존 `candidate-admin-tutorial`의 CodePen embed `GreenSock/LYpgKPe`가 실제 브라우저에서 404로 표시됐다. 이전 정상 실행 기록이 남아 있어 새 검수 화면에서는 처음에 `최종 확인 1`로 분류됐다. owner 화면에서 실행 실패를 다시 기록하고 새로고침한 결과 `최종 확인 0`, `기존 실패 1`로 바뀌었다. 후보는 자동 거절하거나 공개하지 않았다.

외부 CodePen 요청의 403 또는 네트워크 오류만으로 404를 확정하지 않는다. 실제 접근 가능 여부와 Hero 영역 적합성은 관리자 Preview 검수로 결정한다.
