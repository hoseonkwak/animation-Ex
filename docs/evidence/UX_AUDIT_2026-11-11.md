# 공개 홈페이지 사용성 점검 — 2026-11-11

## 점검 범위

- Production 공개 화면을 데스크톱 브라우저에서 직접 탐색했다. Home의 추천 카드 12개 미리보기 버튼을 모두 열고, Explore 검색·정렬·그리드·필터, Sections 허브와 상세, 예제 상세, Saved, Practice, URL 제보, About, 테마 전환과 주요 이동 링크를 눌러 확인했다.
- 카드 12개의 미리보기 모달은 모두 열렸다. CodePen 실행 화면 자체가 모든 기기와 브라우저에서 성공한다는 뜻은 아니다. 외부 CodePen iframe의 접근 차단은 사이트가 통제할 수 없다.
- 전체 공개 예제 1,879개를 개별 검수하거나 모바일 기기에서 확인한 점검은 아니다. 제보는 실제 전송하지 않았다.

## 후속 확인

1. Hero 재분류 화면에서 실제 첫 화면 구성·모바일 표시·움직임을 확인하고 후보를 확정한다. 전용 Hero 출처를 따로 만들지 않고 전체 수집 범위와 공통 분류를 개선한다.
2. 모바일 390px, 태블릿, 키보드 조작과 CodePen 차단 브라우저에서 주요 경로를 다시 점검한다.
3. `랜딩` 같은 한국어 검색어가 관련 영문 예제로 이어지는지, 동의어 검색 도입 후 측정한다.
