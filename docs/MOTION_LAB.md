# Motion Lab 소개

문서 상태: Living Document
기준일: 2026-10-07

## 한 문장으로 소개

Kwak Motion Lab은 웹 애니메이션 예제를 카테고리와 기술별로 찾고, 썸네일을 누르면 실제 코드가 실행되는 화면으로 확인할 수 있는 한국어 모션 레퍼런스 라이브러리다.

## 왜 만들었나

웹 애니메이션 레퍼런스는 여러 사이트와 개인 작업물에 흩어져 있다. 마음에 드는 효과를 발견해도 어떤 기술로 만들었는지, 실제로 실행되는지, 비슷한 예제는 어디에 있는지 다시 찾기 어렵다.

Motion Lab은 이 과정을 하나의 흐름으로 연결한다.

```text
예제 발견 → 카테고리 탐색 → 실제 실행 → 출처 확인 → 저장 → 직접 연습
```

단순히 보기 좋은 화면을 모으는 데서 끝나지 않고, 구현 방법을 확인하고 직접 수정해 볼 수 있는 학습 도구로 발전하는 것이 목표다.

## 누구를 위한 페이지인가

- 웹사이트에 적용할 모션 아이디어가 필요한 디자이너와 개발자
- GSAP, CSS, JavaScript 애니메이션을 공부하는 초급자와 중급자
- Hero, Navigation, Slider, Button, Text처럼 적용 영역별 예제를 빠르게 찾고 싶은 사람
- 마음에 드는 예제를 저장해 두고 나중에 직접 만들어 보고 싶은 사람

## 무엇을 할 수 있나

### 카테고리에서 바로 찾기

첫 화면에는 짧은 소개 다음으로 카테고리와 예제 목록이 바로 나온다. 사용자는 긴 설명을 읽지 않아도 원하는 영역을 선택하고 예제를 탐색할 수 있다.

### 조건을 조합해 탐색하기

예제 탐색 화면에서는 검색어와 다음 분류를 함께 사용할 수 있다.

- 기술: GSAP 등
- 트리거: 로드, 호버, 포인터, 드래그, 스크롤
- 모션: 슬라이드, 스케일, 리빌, 모핑, 그리기, 색상 전환
- 영역: Hero, Card, Gallery, Text, Background 등
- 기법: Timeline, Stagger, ScrollTrigger, Draggable 등
- 난이도: 입문, 중급, 고급

최신순, 추천순과 난이도순으로 결과를 정렬할 수도 있다.

### 실제 코드 실행 화면 보기

목록에서는 예제를 고르기 쉽도록 썸네일을 먼저 보여준다. 썸네일을 누르면 같은 자리에서 실제 CodePen 실행 화면으로 전환된다. 이미지, GIF나 녹화 영상으로 움직임을 대신하지 않는다.

브라우저가 무거워지는 것을 막기 위해 목록에서 동시에 실행하는 예제 수를 제한한다. 자세히 보고 싶은 예제는 상세 화면에서 다시 실행하거나 전체 화면으로 보고, 원본 CodePen으로 이동할 수 있다.

### 예제의 맥락과 출처 확인하기

상세 화면에서는 예제의 난이도, 기술, 트리거, 모션과 관련 패턴을 함께 보여준다. 외부 CodePen 예제에는 제작자, 원본 주소와 확인 가능한 라이선스 정보를 표시한다.

### 로그인 없이 저장하기

회원가입 없이 예제를 저장하거나 `나중에 연습` 목록에 넣을 수 있다. 이 정보는 현재 사용하는 브라우저에 저장되므로 브라우저 데이터를 삭제하면 함께 사라질 수 있다.

### 좋은 사례 제보하기

CodePen 또는 공개 웹페이지 URL을 제보할 수 있다. 제보한 주소는 곧바로 공개되지 않는다. 실행 여부, 출처, 라이선스와 중복 여부를 확인한 뒤 후보로 등록한다.

## 콘텐츠는 어떻게 들어오나

Motion Lab은 WSSS 같은 디렉터리와 공개 웹에서 애니메이션 사례를 발견한다. WSSS는 발견 경로로 기록하고 실제 실행과 출처의 기준은 원본 CodePen으로 관리한다.

수집한 콘텐츠는 바로 공개하지 않고 다음 흐름을 거친다.

```text
발견 → 메타데이터 추출 → 중복 확인 → 분류 → 실행 확인 → 관리자 검수 → 공개
```

기존 CodePen 콘텐츠는 원작자와 원본 정보를 유지한다. 일반 웹사이트에서 발견한 패턴은 원본의 로고, 문구와 독점 에셋을 복사하지 않고 샘플 텍스트, 이미지와 SVG를 사용해 새로운 학습용 코드로 제작한다.

## 화면 구성

| 화면           | 역할                                               |
| -------------- | -------------------------------------------------- |
| Home           | 카테고리와 추천 예제를 바로 보여주는 시작 화면     |
| Explore        | 검색, 필터와 정렬로 전체 예제를 탐색하는 화면      |
| Sections       | Hero, Navigation, Button 같은 적용 영역별 모음     |
| Example Detail | 실제 실행 화면, 태그, 출처와 관련 예제를 보는 화면 |
| Saved          | 이 브라우저에 저장한 예제와 연습 목록              |
| Submit         | 새로운 CodePen 또는 웹 사례를 제보하는 화면        |
| About          | 실행 원칙, 출처 정책과 저장 방식을 설명하는 화면   |

## 디자인 원칙

기본 테마는 밝은 화면이다. 반투명 표면, 부드러운 곡선과 은은한 색 번짐을 사용하는 Liquid 디자인을 적용하되, 장식보다 예제 썸네일과 탐색 정보가 먼저 보이도록 구성한다. 어두운 테마는 사용자가 선택할 수 있다.

## 앞으로 추가할 경험

Motion Lab은 실행형 라이브러리부터 시작해 다음 기능으로 확장한다.

1. 예제 코드를 HTML, CSS와 JavaScript로 직접 수정하는 Practice 화면
2. 자유 연습과 단계별 미션
3. 작성 중인 코드의 브라우저 자동 저장과 복구
4. CodePen으로 내보내기
5. 한국어 튜토리얼과 구현 원리 설명
6. 일반 웹 모션 패턴의 코드 재구성과 자동 검증

현재 공개 화면에 없는 기능은 검증을 마친 뒤 단계적으로 제공한다.

## 운영 원칙

- 실행 가능한 콘텐츠만 공개한다.
- 출처와 제작자를 추적할 수 있게 기록한다.
- 중복, 실행 오류와 접근 불가 콘텐츠를 공개에서 제외한다.
- 자동화가 실패하면 원인을 기록하고 조용히 건너뛰지 않는다.
- 초기 사용 경험은 무료이며 회원가입 없이 이용할 수 있다.
